# Benchmark: Laravel Reverb vs reverb-rs

Generated by `cargo run --release --example benchmark` on 2026-09-29.

## Method

Both servers were given identical work: the same number of subscribers on one
channel, the same number of events, the same payload size. Each server was
restarted before every measurement, each scenario ran 3 times, and the median is
reported. The load generator is the same Rust client in both cases, and it pools
its HTTP connections so it is not itself the bottleneck.

CPU is read from `/proc/<pid>/stat` (user + system) across the measured window.
Memory is `VmRSS` when idle and `VmHWM` at peak. Wire throughput counts payload
plus WebSocket frame headers, not TCP/IP overhead.

| | |
|---|---|
| Host | 14 cores, Linux 7.2.2-arch1-1 |
| Laravel Reverb | cb71efc on PHP 8.5.10 |
| reverb-rs | rustc 1.93.1 (01f6ddf75 2026-02-11) |
| Repeats per scenario | 3 (median reported) |

> **Caveats.** Both servers ran on loopback on the same host as the load generator, so network latency is excluded and CPU is shared with the client.

## Reading these numbers

**CPU per message** is the metric that survives a change of hardware. It is the
work each server does to put one frame on one socket, independent of how many
cores are available — Reverb is single-threaded by design, so its wall-clock
results also reflect having only one core to use.

**Wire throughput** is measured over loopback, so the figures are far above what
any real network interface would carry. Read them as a ceiling the server does not
impose, not as a rate you will see in production.

**Memory per connection** is peak RSS minus idle RSS, divided by the connection
count. PHP's allocator reuses a pool, so its figure moves around between runs more
than the Rust one does.

**HTTP publish rate** is how fast the server accepts events on its Pusher API. In
the fan-out scenarios this bounds the measured window: a server that accepts
events slowly cannot deliver them quickly either.

Reproduce with:

```bash
cargo build --release
cargo run --release --example benchmark -- --reverb-php /path/to/reverb-checkout
```
